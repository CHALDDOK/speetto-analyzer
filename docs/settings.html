GitHub 토큰 만드는 법

  1. 새 토큰 만들기(Fine-grained)를 엽니다.
  2. Repository access → Only select repositories → speetto-analyzer
  3. Repository permissions → Contents: Read and write만 켭니다.
  4. 만든 토큰(github_pat_…)을 붙여 넣고 저장합니다.

토큰은 이 기기의 브라우저에만 저장되고 GitHub 외의 곳으로는 보내지 않습니다. 기기를 잃어버리면 GitHub에서 토큰을 삭제하세요.
