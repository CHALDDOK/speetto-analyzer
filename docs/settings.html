저장

설정은 GitHub 저장소의 알림 설정 파일에 저장됩니다. 저장하려면 이 저장소에 쓰기 권한이 있는 GitHub 토큰이 필요합니다.

토큰 만드는 방법
  1. GitHub 새 토큰 만들기(Fine-grained)를 엽니다.
  2. Repository access에서 Only select repositories → speetto-analyzer만 고릅니다.
  3. Permissions → Repository permissions → Contents: Read and write만 켭니다.
  4. 만든 토큰(github_pat_로 시작)을 위 칸에 붙여 넣습니다.

토큰은 이 기기의 브라우저에만 저장되고, GitHub 외의 곳으로는 보내지 않습니다. 이 저장소 하나에만 권한을 주고, 기기를 잃어버리면 GitHub에서 토큰을 삭제하세요.
